## 工程实现选择（由 coding 负责同学决定，可随时复议）

- 上游模型/训练器不依赖 PyG（见 D-013），数据与划分代码不依赖 torch，便于 CPU 与 CI 验证。
- 负样本在数据构建阶段一次性抽样并写入数据集，所有模型共用同一份，避免"每个模型自己的负样本"造成不可比。
- 模型 B4–B7 在注册表中显式抛 `NotImplementedError`，防止用占位实现产出消融表。
