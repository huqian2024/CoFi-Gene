# CoFi-Gene 首轮真实数据 GPU 训练

2026-11-16，真实数据上游 Link Prediction，seed 42。严格 CUDA 探针与数据集校验通过，测试 187 项通过，1 项按 CUDA 可用性跳过。

## 数据与设置

- 数据集包含 18,002 个基因和 128 维共享特征。图 A 为 STRING 实验关联（144,071 条边），图 B 为共表达（871,260 条边），其中 42,035 条重合，Jaccard 为 0.04319。使用人类 9606、STRING v12.0 的详细关联文件，阈值 A≥400、B≥150。 [STRING 下载](https://string-db.org/cgi/download?species_text=Homo+sapiens)
- PIE gene_text 从 3,072 维统一 PCA 至 128 维，按发布元数据的键顺序对齐。四个细胞系的 DE 表共 36,258,678 行，1,833/1,857 个扰动目标与图节点对齐（98.71%）。候选标签为 p_adj < 0.05。特征矩阵和四份 parquet 的 SHA-256 均通过发布记录校验。 [PIE 特征版本](https://huggingface.co/datasets/arcinstitute/PIE_sources/tree/ae4ce640b7edff7ac4acfd1abed74ca4138e5931) · [PIE DE 版本](https://huggingface.co/datasets/arcinstitute/PIE_replogle_nadig_essential/tree/5119439699a8a02b0f6ebe593cf0dd373891bd37)
- 各模型共用同一份划分和构建期固定的 1:1 正负样本，测试阳性率 50%。采用交接配置的「另一视图可见」口径。图模型使用验证集选择权重，最多 200 epoch。B0 对 128 维 PCA 特征直接点积打分，训练步数为 0。
- 环境为项目专用 Python 3.11.15、PyTorch 2.5.1+cu121、PyG 2.8.1、RTX 4090（24 GB）、驱动 580.178.04。
